# 产品与资产

产品与资产分别承担“标准化定义”和“业务对象承载”两类职责。

## 产品管理

菜单入口：

- 产品管理 > 产品列表

从当前前端实现看，产品页包含：

- 产品列表
- 产品表单
- 数据字典
- 数据映射设计
- 产品属性配置
- 批量创建设备

适合场景：

- 统一设备型号定义
- 管理默认属性与接入参数
- 量产设备时减少重复配置

## 资产管理

菜单入口：

- 资产管理 > 资产列表

资产页对应前端能力包括：

- 资产列表
- 资产详情
- 资产设计器

适合场景：

- 组织设备归属关系
- 为站点、产线或设备系统建立业务对象，并关联设备的属性、遥测点位
- 从业务视角聚合点位和设备状态

当前 Asset 保存业务对象及点位关系，尚不提供独立的无点位设备绑定、资产树或负责人模型。资产层级、现场责任人和批准范围应保存在经批准的业务清单中，并以 Asset ID 关联；不能把 Tenant/Customer 技术归属当作现场责任确认。生产启用需逐项完成[生产闭环验收](../operations/production-loop-acceptance.md)。

## 推荐使用方式

- 先用产品统一建模
- 再用设备完成实例化
- 最后用资产承载业务场景并关联实际点位，保留外部业务层级及责任清单
