# SonnetDB 能力对接记录

基线：2026-10-16 读取的 SonnetDB `main` 为 `67a5c8c8d64c36002aee5ebcfcb40634e7d5f482`，本仓服务端、ADO.NET、EF、缓存、对象和 MQ 客户端均从同一子模块构建。GitHub 最新正式 Release 为 v4.0.0；本次交付是更新的源代码快照加邮箱账号与凭据脱敏补丁，不能标作新的正式 Release。

| SonnetDB 能力 | IoTSharp 所需用途与接入位置 | 当前证据和边界 |
| --- | --- | --- |
| 关系模型与 EF | Product、Device、Asset、租户、Identity、配置、发布中心；`IoTSharp.Data.SonnetDB` | 升级统一 provider；本地迁移/组件测试通过；现场版本切换待完成 |
| 时序模型 | 设备遥测、历史与聚合；`SonnetDBStorage` | 最新非空值下推 `ORDER BY time DESC LIMIT 1`；对齐桶一次查询多字段；稀疏/乱序测试通过。非 epoch 对齐桶保持原始 begin 起点兼容路径，不宣称全部查询次数固定为 1 |
| KV 与缓存 | 会话辅助、验证码和平台缓存；`SonnetDB.Caching.EasyCaching` | 既有客户端随子模块统一升级，未更改缓存与业务数据边界 |
| 对象存储 | 平台 Blob、软件/配置工件 | 既有 `SonnetDbBlobStorage` 保持接口并升级依赖，实际上传回读待验证 |
| SonnetMQ | 遥测、属性、规则事件的持久队列 | `IoTSharp.EventBus.SonnetMQ` 保留消费、确认和重试，升级 SndbMqClient；实例 MQ 与单数据库备份不同，必须按实例数据根整体备份 |
| SQL、Schema、诊断 | 数据查询、运维、慢查询 | 管理端按数据库权限开放；密码 SQL 的诊断样本和 SSE 脱敏已补回归，不能公开内部数据库管理 token |
| 文档/JSON | 可扩展配置、业务文档 | 数据引擎与客户端能力随版本可用；现有平台领域继续经 EF/版本化 DTO 管理，不无依据搬迁现有配置数据 |
| 图、全文、向量、地理 | 后续资产关系、知识检索、地图与诊断 | 数据库管理端可按授权使用；平台本体和 AI 仍遵守领域规划，不把引擎能力可用写成平台业务已实现或预测已验证 |
| 备份恢复与维护 | 发布前一致性备份、故障恢复 | 实机已停写归档整个实例及配置，并用新版在副本中读取旧账号/表成功；不能把 API 健康或单库备份写成全实例恢复 |
| 多用户权限 | 公共演示与真实注册租户 | IoTSharp 独立演示租户；SonnetDB 演示只授权 demo 数据库；邮箱用户名、定向改密、保留其它密码的测试通过；实机账号与跨库验证待完成 |

最终通过 36 项 IoTSharp 定向测试、53 项 SonnetDB 账号/权限/诊断测试和 52 项控制面解析测试。真实公开登录、注册、MQ/遥测、对象隔离与重启保留见 [发布回执](deployment-receipt.md)；表格中的“待验证”为初始检查点，已由该回执更新。文档/图/向量/全文等后续业务仍按表中领域边界，不把引擎支持写成平台业务已实现。
